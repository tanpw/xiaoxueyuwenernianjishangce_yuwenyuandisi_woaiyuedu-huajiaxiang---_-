> 小学语文 · 二年级上册 · 单元四 · 语文园地四 · 我爱阅读

## 📖 课文简介

**《画家乡》** 是一篇语言浅显优美的短文，描写海边、山里、平原、草原、城市五个孩子画家乡，是小学生经典阅读篇目。

- **作者**：冯寿鹤（上海小学语文教育专家）
- **教材出处**：最早收录于人教版一年级下册语文，新版统编教材放在二年级上册·语文园地四「我爱阅读」
- **入选时有改动**

### 作者简介

冯寿鹤，上海小学语文教育专家，统编语文课文《画家乡》的作者，曾任上海市教委教研室小学语文教研员、上海市教育学会小学语文教学专业委员会秘书长。长期从事小学语文教研、课堂评课、教师培训，发表多篇小学语文教学论文，主编小学生优秀作文选、小学语文主题阅读等教辅读物。

## 📝 课文全文

孩子们爱家乡，也爱画自己美丽的家乡。

涛涛的家乡在海边。他画的海那么蓝，那么宽。一艘艘船上装满了鱼和虾。那个在海滩上赤着脚捡贝壳的孩子，就是涛涛。

山山的家乡在山里。她画的山那么高，水那么清。房前屋后都是又高又大的树。画上的山山，提着小竹篮，正要到树林里去采蘑菇呢。

平平的家乡在平原。她画的平原那么平坦，那么宽广。有金黄的稻子，雪白的棉花，还有一大片一大片碧绿的菜地。屋前有鸡、鸭，屋后有几丛青翠的竹子。那个正在田野上奔跑的小女孩，就是平平。

青青的家乡在草原。他画的草原一眼望不到边。草长得又绿又密，羊群在草原上走来走去。一匹骏马从远处奔来，青青正骑在马上赶着羊群。

京京的家乡在城市。他画的城市那么美。宽宽的街道，高高的楼房，还有一座座街心公园。那个正跑向科技馆的小男孩，就是京京。

小朋友，你的家乡也一定很美，请你画出来吧！

## 🎯 使用说明

### 文件命名规则

- 文件名格式：`序号+标识字.扩展名`（例如 `2涛.png`）
- **序号** `0` ~ `24` 代表课文的阅读顺序，按数字排序即可依次浏览/播放
- **标识字** 仅用于区分同名文件，实际内容见图片底部的字幕
- 例外：第 4 段音频拆成了 `4a一.mp3` 和 `4b装.mp3` 两个文件

### 素材类型

| 扩展名 | 说明 |
|:---:|------|
| `.png` | 课文逐句场景插画（含文字字幕，适合投影展示或打印成绘本） |
| `.mp3` | 对应句子的朗读音频（适合跟读音训练） |

### 教学建议

1. **看图朗读**：按序号顺序播放图片 + 音频，让学生跟读模仿
2. **分角色朗读**：五个孩子分别代表海边、山里、平原、草原、城市，可分组合作表演
3. **拓展绘画**：读完后让学生"画自己的家乡"，仿照课文句式介绍
4. **识字游戏**：利用图片中的文字进行识字教学
